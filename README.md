# Alexhzier C. Asdain — Engineering & Creative Technology Portfolio

A dark-mode, editorial portfolio designed with elevated typography, real-time 3D ambient physics, and strict accessibility standards.

**Degree**: Bachelor of Science in Computer Science (Graduated 2026)

---

## 🛠️ Tech Stack & Architecture

- **Core Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + PostCSS
- **3D Graphics & Physics**: Three.js (`Floating3DCanvas` ambient depth field)
- **Typography & Aesthetics**: Geist Mono & Sans, zinc-950 base, electric violet (`#8b5cf6`) accents
- **Optimization**: Zero horizontal layout shifts, fluid responsiveness across 360px–1440px+ viewports

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
git clone https://github.com/Alexhzier/portfolio.git
cd portfolio
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
